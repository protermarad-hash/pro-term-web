# Pornire rapidă în VS Code

## Deschide proiectul

1. Deschide VS Code.
2. Alege **File > Open Folder**.
3. Selectează folderul `C:\Users\frigo\develop\pro-term-web`.
4. În colțul din stânga jos, verifică să nu fie afișat branch-ul `main`. Pentru această configurare trebuie să apară `chore/vscode-beginner-workspace-setup`.

## Pornește și oprește site-ul

1. Deschide **Run and Debug** din bara din stânga.
2. Alege **PRO TERM: Deschide site-ul local**.
3. Apasă butonul verde de pornire. Site-ul se deschide local în browser.
4. Pentru oprirea site-ului local, revino în VS Code și apasă **Shift + F5** (aceeași comandă se găsește în meniul **Run > Stop Debugging**).

## Deschide asistenții

- Pentru Codex, apasă pictograma **ChatGPT/Codex** din bara din stânga.
- Pentru Claude Code, apasă pictograma **Claude Code** din bara din stânga.
- Dacă pictograma lipsește, deschide **Extensions** și verifică extensiile recomandate ale proiectului. Instalarea rămâne o alegere manuală.

## Reguli importante

- Nu lucra direct pe `main`; verifică branch-ul înainte de orice schimbare.
- Nu accepta **merge**, **push** sau **deploy** fără ca verificările proiectului să fie finalizate și rezultatul să fie verificat.
- Dacă apare o eroare, copiază mesajul exact și cere ajutor în Codex sau Claude Code. Nu aproba o acțiune pe care nu o înțelegi; dacă eroarea persistă, contactează persoana care administrează proiectul.
